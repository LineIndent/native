# When To Use This Skill

Use this skill when the user asks about:

- Installing Native
- Creating a new Native project
- Setting up a development environment
- Running a Native application
- Using Native CLI commands
- Understanding the basic project structure
- Troubleshooting setup issues

# Guidance

When helping with setup:

1. Check the documented workflow first.
2. Prefer official Native commands and patterns.
3. Avoid suggesting undocumented configuration.
4. Include the relevant documentation link when useful.
5. Keep examples consistent with the current Native API.

# Do Not Use This Skill For

Do not use this skill for:

- Building UI components
- Component APIs
- Application state
- Events
- Styling and theming
- Charts
- Internal architecture

Use the more specific skill instead.
